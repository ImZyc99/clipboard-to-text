# 剪贴成文

把微信、飞书等应用中复制的口播稿、提示词或图片，直接保存到桌面。启动后常驻菜单栏，无需打开主窗口，不显示 Dock 图标。

## 使用

1. 打开「剪贴成文」，顶部菜单栏出现透明底的剪贴板线条图标。
2. 复制一段文字或一张图片。
3. 点击菜单栏图标 → **将剪贴板保存到桌面**。

也可启用 **桌面 ⌘V**：点击菜单栏的「启用桌面 ⌘V…」，在系统设置的「隐私与安全性 → 辅助功能」打开「剪贴成文」。之后复制文字或图片，点一下真正桌面空白处，再按 ⌘V，即可生成 TXT 或 PNG。菜单栏可随时暂停此功能，手动保存不依赖辅助功能。

快捷键只在确认桌面焦点后读取本次内容；其他应用、Finder 文件夹窗口、搜索/重命名与文件复制不参与转换。不记录按键或剪贴板历史，长按不连发。采用被动监听，Finder 原有提示音可能保留；授权及本机桌面交互需完成实测后才视为验收通过。

菜单还提供打开桌面、右键扩展状态、管理右键扩展、设置与使用说明、退出。设置窗口仅在主动选择时打开，关闭后工具继续运行。退出后菜单栏图标消失；Finder 扩展由系统管理，后续通过扩展保存时可重新启动宿主。本版不自动添加登录启动项。

桌面右键入口需要先从「管理右键扩展…」启用同名 Finder 扩展。目前已在 Finder 的桌面文件夹窗口验证；**真实壁纸桌面菜单仍在定位，尚未验收**，菜单栏入口可独立使用。

文字生成 UTF-8 `.txt`，按第一行非空文字自动命名，重名自动加序号。正文中的换行、空行和 Emoji 原样保留。只在保存时读取剪贴板，不联网、不保存剪贴板历史。

保存成功后文件直接留在桌面，不打开 Finder 窗口、不弹成功提示。只有主动选择「打开桌面」时才打开文件夹窗口。需要桌面访问时，按系统提示授权。

## 图片保存

- 支持剪贴板中的 PNG、TIFF（包括截图）、JPEG 及系统能解码的其他位图，保存为 PNG；保留像素尺寸、透明背景和显示方向。有效单帧 PNG 保留原始字节。
- 自动命名为 `图片 yyyy-MM-dd HH.mm.ss.png`，重名加序号，已有文件不覆盖。
- 图片附带文字或网址时只保存图片；只有网址时仍生成文本，不下载网页图片。
- 复制已有图片文件时由系统直接粘贴，不重复转换。多个图片项仅保存第一张，动图/多页图片只取首帧。
- 损坏图片提示失败，不生成空文件；超出 256 MiB / 100 MiPixel 的输入提示过大。
- 菜单保存和桌面 ⌘V 共用图片处理；独立剪贴板验收已覆盖，真实桌面交互仍需本机确认。

## 本机构建

需要 macOS 13+、Apple Silicon/Intel 对应架构的 Command Line Tools。当前只验收本机架构。

```sh
./scripts/test.sh
./scripts/build.sh
./scripts/install.sh
```

构建产物：`build/剪贴成文.app`。安装到 `~/Applications/剪贴成文.app`。

默认 ad-hoc 签名，用于本机开发；没有公证，不是可面向其他电脑直接分发的安装包。可通过 `CLIPTEXT_SIGN_IDENTITY` 指定已有签名身份。
辅助功能权限只在主动启用时请求。开发版替换二进制后可能需要重新授权；正常运行不会每次粘贴都请求权限。

### 更新后桌面 ⌘V 无反应

先确认菜单栏工具正在运行、桌面 ⌘V 未暂停。开发版更新后，系统可能仍显示辅助功能开关已开启，但保留的是旧版签名的授权。若关闭再开启无效，在「系统设置 → 隐私与安全性 → 辅助功能」移除「剪贴成文」，再用加号添加当前的 `~/Applications/剪贴成文.app` 并启用；按系统提示完成验证。随后复制测试文字，点击真正桌面的空白壁纸，再按 ⌘V 检查。无需重新安装应用。

## 技术

AppKit 菜单栏、SwiftUI 按需设置页、Finder Sync 原生右键扩展、ImageIO 图片处理、Foundation 文件读写；不需要后端。
扩展只发送保存指令到宿主，正文不放入 URL。完成临时文件写入后，以原子不覆盖方式发布最终文件名。

CLT 不包含 XCTest，因此 `scripts/test.sh` 编译并执行独立 Swift 验收程序，覆盖正文、文件名、并发、失败清理、性能，以及独立剪贴板的图片格式/透明度/方向/优先级；不改写用户当前剪贴板。

## 图标

应用使用复古棕底白线图标，菜单栏使用同一剪贴板/文档核心形状的透明底单色模板，适配系统深浅外观。原图见 [Resources/AppIcon.png](Resources/AppIcon.png)，生成说明见 [Resources/Icon.md](Resources/Icon.md)。

## 卸载

在系统设置中关闭 Finder 扩展，退出应用，将 `~/Applications/剪贴成文.app` 移到废纸篓即可。此前保存的文本不受影响。
