# 剪贴成文 Constitution

## Core Principles

### I. 最短保存路径
复制后通过桌面右键一次操作生成已保存文本，不强制命名、打开编辑器或再次保存。

### II. 原文与已有文件安全
正文逐字保留，不改写、不裁剪；命名处理仅作用于文件名。重名不得覆盖已有文件。

### III. 本地与按需处理
只在用户主动保存时读取剪贴板；不监听历史、不联网、不记录正文。

### IV. 原生与小范围
使用 macOS 原生应用及公开接口；第一版仅支持纯文本和桌面目录，无账号、后端或编辑器。

### V. 可验证交付
核心保存逻辑验证原文保留、非法文件名、重名与错误场景；桌面菜单需实机验证，未验证不得声称完成。

## 范围与约束
项目位于 ClipboardToText 子目录，父目录是共享工作区。中文文档，英文代码标识符。
使用系统标准权限流程，不绕过隐私授权，允许首次启用扩展的系统操作。

## 开发流程与质量门槛
按 specify → plan → tasks → analyze → implement → converge 推进，维护同一功能目录。
按风险精简文档和测试。系统限制需如实记录并提供复现步骤。

## Governance
变更同步需求和验证证据；破坏兼容性升主版本，新增原则升次版本，文字澄清升修订版本。
