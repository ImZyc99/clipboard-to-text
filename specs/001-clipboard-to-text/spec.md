# Feature Specification: 剪贴成文

**Feature Branch**: 当前工作区（未建立新分支）
**Created**: 2026-09-17
**Status**: 0.4.0 图片版已安装，核心图片验收通过，待真实桌面图片保存反馈；真实桌面右键仍未通过
**Input**: 将微信、飞书中复制的口播稿、提示词和图片，通过菜单栏、桌面右键或点击桌面后按 ⌘V 自动命名并保存为文件。

## User Scenarios & Testing

### User Story 1 - 一次操作保存原文 (Priority: P1)
用户复制文字后，在桌面空白处右键选择「将剪贴板保存到桌面」，立即获得已保存文件。
**Why this priority**: 省去新建、打开、粘贴、另存为。
**Independent Test**: 复制中文、空行、标点与 Emoji，点击菜单并比较全文。
**Acceptance Scenarios**:
1. Given 剪贴板有文字，When 点击菜单，Then 桌面生成 .txt，全文保留，无命名或保存对话框。
2. Given 首次启用完成，When 保存成功，Then 新文件直接出现在桌面，不自动打开或激活 Finder 窗口，不弹出成功对话框。

### User Story 2 - 自动命名且不覆盖 (Priority: P1)
第一行非空文字命名，处理非法字符与重名。
**Why this priority**: 用户明确选择直接保存。
**Independent Test**: 同一内容保存两次，两文件都存在，原文件未变。
**Acceptance Scenarios**:
1. Given 前几行空白，When 保存，Then 使用第一行非空文字命名。
2. Given 同名文件存在，When 保存，Then 添加「 2」「 3」等序号。
3. Given 首行过长或含路径符号，When 保存，Then 文件名有效可见且正文不变。

### User Story 3 - 失败反馈与首次启用 (Priority: P2)
无文字或无法写入时得到原因；首次有启用引导。
**Why this priority**: 避免误以为保存成功。
**Independent Test**: 空剪贴板和不可写目录下保存，不产生空文件。
**Acceptance Scenarios**:
1. Given 空、纯空白或不支持的内容，When 保存，Then 提示先复制文字或图片且不创建文件。
2. Given 权限被拒，When 保存，Then 提示检查桌面权限，不覆盖原文件。
3. Given 未启用扩展，When 打开应用，Then 可找到启用入口和使用说明。

### Edge Cases
LF、CRLF、CR 和 Unicode 换行；文件名斜杠、冒号、控制字符和隐藏文件前缀；目录重名、并发保存和写入失败。
正文首尾空白保留，纯空白不保存。

### User Story 4 - 菜单栏小工具 (Priority: P1)
用户从顶部菜单栏的小图标使用工具，不需要常驻主窗口。
**Independent Test**: 冷启动后无窗口及 Dock 图标；点菜单栏图标可保存、打开设置，关闭设置后仍可保存。
**Acceptance Scenarios**:
1. Given 应用未运行，When 打开应用，Then 只出现菜单栏图标，不自动打开设置窗口。
2. Given 应用已运行，When 点击图标，Then 显示保存剪贴板、打开桌面、右键扩展状态、设置和退出入口。
3. Given 设置窗口已打开，When 关闭窗口，Then 菜单栏入口保持可用且没有 Dock 图标。
4. Given 用户点击退出，When 应用退出，Then 菜单栏图标消失；再次打开可恢复。
5. 应用图标采用复古棕色底、白色线条的剪贴板/文档标志；菜单栏仅用同一核心元素的透明底单色线条，不带棕色方底，深色菜单栏下为白色，浅色下由系统适配以保持可读。

### User Story 5 - 桌面直接粘贴文字 (Priority: P1)
用户在聊天等其他应用复制文字，点击真正桌面空白处后按 ⌘V，直接生成已保存的 TXT。
**Independent Test**: 开启辅助功能后，复制自建样例并在桌面 ⌘V，比较文件；在编辑器、Finder 文件夹、搜索和重命名时粘贴不生成额外 TXT。
**Acceptance Scenarios**:
1. Given 已启用且系统权限可用，When 真正桌面获得焦点后按一次 ⌘V，Then 生成一个 TXT，无窗口、无保存对话框。
2. Given 其他应用、Finder 文件夹窗口、搜索框或文件重命名获得焦点，When 按 ⌘V，Then 本应用不创建文件，不影响原有粘贴。
3. Given 剪贴板是文件/文件承诺、无可保存内容或空白，When 桌面 ⌘V，Then 不转成 TXT、不拦截系统文件粘贴。
4. Given 按住 ⌘V 产生自动重复键事件，Then 本次按住只保存一次；主动重复按键仍按原规则添加序号。
5. Given 未授权或开关关闭，Then 菜单显示明确状态，普通粘贴不受影响；授权仅用户主动开启时请求，不在每次粘贴时弹授权。

### User Story 6 - 图片直接保存 (Priority: P1)
复制图片或截图后，在桌面按 ⌘V 或从菜单保存，直接得到可打开的 PNG。
**Independent Test**: 使用专门的透明 PNG、TIFF、JPEG 样例，检查保存后像素尺寸/透明度和重名安全。
**Acceptance Scenarios**:
1. Given 剪贴板是一张图片，When 保存，Then 桌面生成 PNG，保持显示方向、清晰度和透明度，不弹成功窗口。
2. Given 同名 PNG 或同名目录已存在，When 再次保存，Then 自动加序号且原内容不变。
3. Given 图片同时带文字或网址，When 保存，Then 仅生成图片；只含网址时仍保存 TXT。
4. Given 已复制图片文件，When 桌面 ⌘V，Then 系统按原文件粘贴，本应用不另外生成 PNG 或 TXT。
5. Given 图片损坏或读取期间剪贴板变化，When 保存，Then 不产生错误文件；损坏图片有中文说明，快捷键对过期快照静默放弃。

## Requirements

### Functional Requirements
- FR-001: 在真实桌面壁纸空白处（含「更改墙纸」「编辑小组件」的菜单）直接右键显示「将剪贴板保存到桌面」。不得要求先打开 Finder 的桌面文件夹窗口。
  - 桌面目录中的文件右键也可显示同一保存动作；无论是否选中文件，都按剪贴板内容新建文件到桌面，不修改选中文件。
- FR-002: 仅主动保存时读取内容；文字以 UTF-8 无 BOM 保存 .txt，正文不变；图片按 FR-014 保存。
- FR-003: 首行非空文字命名，最多 60 个可见字符且不超过 180 字节，过滤非法字符；无有效名字回退「未命名」。
- FR-004: 重名加序号，并发时亦不覆盖。
- FR-005: 保存到系统桌面目录；保存成功后不自动打开或激活 Finder、不自动选中文件，也不弹成功对话框。用户主动点击「打开桌面」时才打开文件夹窗口。
- FR-006: 主动点击保存菜单时，无可保存内容及写入失败有中文提示，不留下空白占位文件。桌面 ⌘V 对无可保存内容按 FR-012 静默忽略，写入失败仍提示。
- FR-007: 首次启用扩展有引导，无联网或账号，不持续监听剪贴板。
- FR-008: 启动时仅显示菜单栏图标，不自动开窗口且不显示 Dock 图标；设置从菜单显式打开，关闭设置不退出。
- FR-009: 菜单栏提供保存剪贴板、打开桌面、右键扩展状态与启用入口、设置、退出；保存复用原有正文保真与防覆盖规则。
- FR-010: 提供复古棕底白线应用 logo，实际用于应用包和设置页；应用图标圆角方形内部必须完全不透明（alpha=255），仅外侧和边缘抗锯齿保留透明。菜单栏为同核心元素的透明底单色线条。交付应用 PNG 图标。
- FR-011: 新增可关闭的桌面 ⌘V 保存入口，仅在确定真正桌面焦点且非编辑/重命名时响应；不依赖 Finder 扩展是否启用。
- FR-012: 保留其他应用与 Finder 原有粘贴；快捷键不处理文件/文件承诺、无可支持内容或纯空白，不记录键盘输入、不监听剪贴板历史，忽略自动重复。粘贴时读取本次内容快照；剪贴板在读取期间发生变化时放弃该次保存。
- FR-013: 菜单与设置展示开关和辅助功能授权状态；仅主动启用时请求系统授权，权限缺失、焦点不明或监听失败时不创建文件。

- FR-014: 菜单栏、已有右键动作和桌面 ⌘V 支持剪贴板图片；可解码 PNG/TIFF/JPEG 等位图保存为 PNG，保持完整像素尺寸及透明度，方向与原图显示一致。有效单帧 PNG 原字节保留；其他格式无损编码为 PNG，动画只保存首帧。损坏/不支持图片提示失败，不生成空文件或误存成文本。
- FR-015: 图片名为「图片 yyyy-MM-dd HH.mm.ss.png」，重名加序号，永不覆盖已有文件/目录。
- FR-016: 同一剪贴板包含图片和文字/链接时优先保存一张图片；多个图片项仅取首个图片项。已有文件及文件承诺优先于图片，桌面 ⌘V 保留系统粘贴；手动保存提示用系统粘贴。仅复制图片链接时按文字保存，不联网取图。

### Key Entities
- 剪贴板文字：本次主动复制内容，只保留本次保存的内存副本。
- 文本文件：桌面上的文件名、原始正文、保存路径。
- 剪贴板图片：用户主动复制的图片数据；只保存当前单张，验证尺寸、方向、透明度和输入限制。
- 图片文件：桌面上的 PNG，时间命名，重名递增。

## Success Criteria

### Measurable Outcomes
- SC-001: 首次启用后，仅右键与一次菜单点击即可保存，无保存对话框。
- SC-002: 10 万字以内样例在正常本机桌面 2 秒内出现文件。
- SC-003: 中文、空行、混合换行、Emoji 测试正文全部准确保留。
- SC-004: 连续与并发重名保存无旧文件丢失；失败不残留空文件。
- SC-005: 冷启动、关闭设置、重新打开应用均无自动主窗口；菜单可访问且保存样例正文一致。
- SC-006: 桌面 ⌘V 的正文与防覆盖验收通过；其他应用、文件夹窗口、重命名、文件剪贴板、重复键的负向测试不生成额外文件。
- SC-007: PNG 原字节、TIFF 透明像素/尺寸、JPEG 尺寸/方向、图片优先和图片重名防覆盖测试通过；本机图片粘贴生成 PNG 可打开且不弹 Finder。

## Assumptions
- 仅处理用户主动复制的纯文字或图片，不读取聊天记录或自动截图，不合并多条消息。每次最多保存一张图片。
- 图片输入超过 100 MiPixel 或 256 MiB 时提示过大，不执行大额解码；不承诺动图动画、图层或原格式元数据。
- 目标用户当前 Apple Silicon Mac；其他版本兼容性独立标注。
- 首次按系统流程启用 Finder 扩展和桌面访问权限。
- 无 AI 和外部服务，暂不提供格式和目录设置。
- 菜单栏属于运行中的本地应用；本次不新增登录自启动，右键入口原验收项继续保留。
