# 验证与运行

前置：Apple Silicon Mac、macOS 13+、Xcode Command Line Tools。

```sh
./scripts/test.sh
./scripts/build.sh
./scripts/install.sh
```

打开安装后的「剪贴成文」，在系统 Finder 扩展设置启用它。
复制样本文字（含中文、空行、Emoji），在桌面空白处右键保存；验证 .txt 原文和自动文件名。
重复保存应产生序号文件。清空或复制图片后保存应有中文提示且不产生文件。
需要系统桌面访问时按 macOS 提示授权；不可用时先检查扩展是否启用。
验证证据与未验证内容记入 validation.md。
# 菜单栏验收
启动后查看顶部图标，确认无主窗口、无 Dock 图标。点击图标显示保存、打开桌面、扩展状态、管理扩展、设置、退出。打开设置再关闭，菜单仍可操作。复制测试文字并从菜单保存，比较原文；退出后菜单图标消失，再次打开恢复且不弹设置。桌面右键仍单独验收。
