# 验证与运行

桌面 ⌘V：点击菜单栏「启用桌面 ⌘V…」，在系统「隐私与安全性 → 辅助功能」打开「剪贴成文」。复制自建文字，点壁纸空白处后按 ⌘V，应出现同名 TXT 且不弹 Finder。再验证其他应用、Finder 文件夹/搜索/重命名、复制文件、长按按键均不产生额外 TXT；测试快速切换焦点及关闭开关。查看菜单授权状态，无需开启输入监控或完整磁盘权限。当前被动监听可能保留系统提示音。

前置：Apple Silicon Mac、macOS 13+、Xcode Command Line Tools。

```sh
./scripts/test.sh
./scripts/build.sh
./scripts/install.sh
```

打开安装后的「剪贴成文」，在系统 Finder 扩展设置启用它。
复制样本文字（含中文、空行、Emoji），在桌面空白处右键保存；验证 .txt 原文和自动文件名。
保存成功应直接在桌面出现文件，不打开/激活 Finder 文件夹窗口；此项同样适用于菜单栏保存。
重复保存应产生序号文件。清空或复制图片后保存应有中文提示且不产生文件。
需要系统桌面访问时按 macOS 提示授权；不可用时先检查扩展是否启用。
验证证据与未验证内容记入 validation.md。
# 菜单栏验收
启动后查看顶部图标，确认无主窗口、无 Dock 图标。点击图标显示保存、打开桌面、扩展状态、管理扩展、设置、退出。打开设置再关闭，菜单仍可操作。复制测试文字并从菜单保存，比较原文；退出后菜单图标消失，再次打开恢复且不弹设置。桌面右键仍单独验收。

## 图片验收
运行 scripts/test.sh：新增独立剪贴板图片验收不会改写系统通用剪贴板。图片尺寸、透明度、方向、字节、图文优先、文件/文件承诺、重名和失败清理均须通过。安装后复制一张截图或聊天图片，点击真实桌面按 ⌘V，确认生成 PNG 可打开，重复保存自动加号、不打开 Finder。复制现有图片文件再粘贴应走系统文件操作，不额外生成 PNG。菜单手动保存同样支持图片。
