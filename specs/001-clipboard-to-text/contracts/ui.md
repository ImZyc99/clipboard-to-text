# 交互与进程接口

- 菜单标签固定「将剪贴板保存为文本」；桌面空白处展示，其他目录不承诺。
- 扩展调用 clipboardtotext://save，不包含正文、路径或文件名。
- 宿主只接受 scheme=clipboardtotext、host=save、无参数和非空路径的请求，忽略其他 URL。
- 点击后读取当前剪贴板一次，目标固定系统桌面，自动命名且不覆盖。
- 写入成功后直接返回，桌面自动显示文件，不打开 Finder、不自动选中、不弹成功通知；「打开桌面」按钮仍可主动打开文件夹。
- 空白剪贴板中文提示「请先复制一段文字」，写入失败给出系统原因及权限建议。
- 设置页有启用扩展、立即保存剪贴板、打开桌面三个动作。关闭设置窗口不影响扩展调用。
- 不提供 HTTP、网络接口或剪贴板历史。
- 冷启动与重新打开应用仅保留菜单栏图标；设置窗口只从菜单「设置与使用说明…」显式打开，全程无 Dock 图标。
- 菜单固定提供「将剪贴板保存为文本」「打开桌面」「右键扩展：已启用/未启用」「管理右键扩展…」「设置与使用说明…」「退出剪贴成文」。展示菜单不读取剪贴板。
- 退出移除宿主菜单栏图标；Finder 扩展不因此禁用，后续主动保存可重新唤起宿主。
- 菜单新增「桌面 ⌘V：已开启/未授权/已暂停」与对应启用/暂停动作；设置页显示同样状态和授权入口。
- 桌面 ⌘V 被动观察，不吞键；只有确认桌面焦点且剪贴板是非空文字才新建 TXT。菜单栏保存仍手动可用且不依赖辅助功能。
